Scroller Renderer

Go is not required to run this package.

1. Install FFmpeg and make sure `ffmpeg` is available on PATH.
   Windows: winget install Gyan.FFmpeg
   macOS:   brew install ffmpeg
   Ubuntu:  sudo apt install ffmpeg
2. Run start.bat on Windows or start.sh on macOS/Linux.
3. Upload your .osr replay in the browser page that opens.

The beatmap and audio must be available in your osu! Songs folder. If the
folder is not detected, set its path in "Pastas locais". FFmpeg must include
the libx264 and AAC encoders.
